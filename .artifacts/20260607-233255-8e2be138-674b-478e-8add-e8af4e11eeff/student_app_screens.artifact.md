# Ntanda Student Mobile App - Screen List

This document outlines all planned screens for the Student persona in the Flutter application.

## 1. Onboarding & Authentication
- **Splash Screen**: Branded entry point.
- **Onboarding Carousel**: 3-4 interactive slides highlighting key features (Offline mode, AI Tutor, Certificates).
- **Login Screen**: Supports Email/Password, Phone Number, and Biometric (FaceID/Fingerprint) toggle.
- **Registration Screen**: Multi-step flow for profile creation.
- **Forgot Password**: Password recovery flow.

## 2. Core Navigation (Main Tabs)
- **Dashboard (Home)**:
    - "Continue Learning" shortcut.
    - AI-Recommended learning paths.
    - Personal stats (Courses, Hours, Points).
- **My Learning**:
    - **Active Tab**: List of currently enrolled courses.
    - **Completed Tab**: Archive of finished courses.
    - **Downloads Tab**: Specialized view for managing offline lessons and storage.
- **Course Explorer (Search)**:
    - Category-based browsing (Healthcare, Education, etc.).
    - Search with filters (Rating, Level, Duration).
- **Notifications**:
    - Real-time updates on assignments, grades, and system alerts.
- **Profile**:
    - **Main Profile**: Profile stats and bio.
    - **Certificates Gallery**: View and share earned credentials.
    - **Settings**: App preferences, data usage, security, and offline storage management.

## 3. Learning Experience (Advanced)
- **Course Details**: Full syllabus, instructor info, and enrollment actions.
- **Lesson Player**:
    - **Video Mode**: Custom player with speed control, PiP, and "Download for Offline" toggle.
    - **Document Mode**: In-app PDF/E-book reader.
    - **Interactive Mode**: HTML5/Scorm-compatible player.
- **AI Tutor Interface**: A contextual chat interface accessible directly within lessons for instant explanations.

## 4. Assessment & Progress
- **Quiz Intro**: Instructions, timer details, and grading criteria.
- **Active Quiz**: Mobile-optimized interactive testing environment with haptic feedback.
- **Quiz Results**: Instant score breakdown with AI-suggested review areas.
- **Gradebook**: Historical view of all quiz scores and overall GPA.

## 5. Community & Support
- **Support Center**: FAQs and ticketing system.
- **Real-time Chat**: Group chats for enrolled courses or direct messages to instructors.
